# Explain code

Explique le code ciblé (fichier ouvert, sélection, ou chemin indiqué) pour un développeur intermédiaire :

1. **Rôle** — à quoi sert ce code dans le projet
2. **Flux** — étapes principales (entrées → traitement → sorties)
3. **Points clés** — patterns, pièges, invariants
4. **Dépendances** — modules / APIs critiques
5. **Améliorations possibles** — seulement si pertinentes (max 3)

Utilise des titres courts et des exemples tirés du code réel. Évite le jargon inutile.
